# Loop MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a local-first Rust desktop MVP where the board runs multiple isolated agent companies with heartbeats, tickets, budgets, governance, and audit via external adapters (Hermes + generic process).

**Status (2026-11-20):** MVP implementation complete in repo — `cargo test --workspace`, `npm test` in `apps/loop-ui`, Tauri shell under `apps/loop-desktop`.

**Architecture:** `loopd` (Axum on `127.0.0.1`) owns SQLite state, scheduling, policy, and adapter dispatch; Tauri 2 embeds a React UI that talks only to `loopd`. Adapters are child processes speaking JSON newline protocol on stdin/stdout. Every DB query is scoped by `company_id`.

**Tech Stack:** Rust 1.78+, Cargo workspace, `sqlx` (SQLite + migrations), `tokio`, `axum`, `serde`, `croner`, Tauri 2, React 18 + Vite + TypeScript.

**Spec:** [`docs/superpowers/specs/2026-11-20-loop-agent-company-os-design.md`](../specs/2026-11-20-loop-agent-company-os-design.md)

## Global Constraints

- MIT license; bind `loopd` to `127.0.0.1` only in v1.
- Multi-company MVP with strict isolation (data, secrets, workspace roots, budgets).
- Budget warn at **80%**, hard stop at **100%** (no wake, agent paused).
- Ticket wake debounce **30s**; default governance gates: **create agent**, **increase budget**, **strategy** tag tickets.
- Adapter protocol: `HeartbeatIn` / `HeartbeatOut` JSON per spec; capabilities `heartbeat`, `assign_ticket`, `shutdown`.
- No telemetry default; no Hermes reimplementation in Rust for v1.
- macOS primary; Linux second.

## Target file layout

```
Cargo.toml                 # workspace
crates/
  loop-core/               # IDs, domain enums, HeartbeatIn/Out, errors
  loop-store/              # sqlx pool, migrations, repositories
  loop-policy/             # budget math, approval gates
  loop-scheduler/          # cron + wake queue (30s debounce)
  loop-adapters/           # Adapter trait, process, hermes
  loopd/                   # Axum routes, DI, main
apps/
  loop-desktop/            # Tauri 2, spawns loopd
  loop-ui/                 # React app (built into Tauri)
```

Frontend API client: `apps/loop-ui/src/api/loopd.ts` — all routes under `/v1/companies/{company_id}/...`.
