# loop

**Hermes Agent** (`hermes-acp`)를 런타임으로 두고, **Paperclip**이 하려는 자율 조직·하트비트·작업·영속 기억을 그 위에 올리는 제품을 만드는 저장소입니다.

이 repo에는 그 방향의 **설계·플랜·코어 코드**만 둡니다.

## 이 repo에 두지 않는 것

- Buzz/loop **데스크톱 포크**, 로컬 릴레이 백엔드, `loop.exe` 빌드 handoff
- Buzz **Pi** 번들, `pi-cursor-sdk`, 멘션 E2E
- Buzz **loop-skills** 플러그인 구현

그런 작업은 별도 작업 트리(포크 클론 등)에만 두고, **여기에는 커밋하지 않습니다.**
